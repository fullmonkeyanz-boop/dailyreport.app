# 勤怠管理アプリ

社内の出勤表(Excel)を置き換える、勤怠入力・集計用の社内Webアプリです。
Python (Flask) + SQLite で作られており、社内LAN上の1台のPCでサーバーを起動すれば、
他のPCからはブラウザでアクセスして入力・閲覧できます。

## 起動方法

初回のみ、必要なライブラリをインストールします。

```
pip install -r requirements.txt
```

起動:

```
python app.py
```

起動すると以下のように表示されます。

```
 このPCから:      http://localhost:5000
 他のPCから(LAN): http://192.168.x.x:5000
```

- サーバーを起動したPC自身からは `http://localhost:5000` でアクセスできます。
- 同じ社内ネットワーク(LAN)にある他のPCからは、表示された `http://192.168.x.x:5000` の
  アドレスをブラウザに入力してアクセスしてください。IPアドレスはPCの再起動やネットワーク環境で
  変わることがあります。アクセスできない場合は、Windowsのファイアウォールで Python (Flask) の
  受信を許可する必要がある場合があります。
- サーバーを起動している間だけ他のPCからアクセスできます。ウィンドウを閉じる/`Ctrl+C`で終了します。
- データは同じフォルダ内の `attendance.db` (SQLite)に保存されます。バックアップする場合は
  このファイルをコピーしてください。

## 使い方

1. **入力**画面で社員と対象月を選び、日ごとに 有休・遅刻・早退・欠勤・早出/残業・休出・現場往復(時間)・
   製番/作業内容 を入力します。入力欄からフォーカスを外す(Tabキーや別セルをクリック)と自動保存され、
   `時間計` は基準労働時間(既定8時間)から自動計算されます(直接上書きも可能です)。
2. **集計**画面で、社員(または全員)と締め月を選ぶと、締め日(既定20日)を基準にした
   「遅刻・早退・早出残業・有休・欠勤・休出・時間計」の月次合計と、現場往復(時間外移動)の暦月合計を
   確認できます。
3. **設定**画面で、休日カレンダー(お盆休みなどの範囲を一括登録可)、締め日、基準労働時間、
   社員の追加・無効化ができます。

## 締め日ロジックについて

遅刻・早退・早出残業・有休・欠勤・休出の6項目は、「締め日の翌日 〜 翌月の締め日」を1つの期間として、
その期間は"翌月度"の実績として集計されます(例: 締め日20日の場合、7/21〜8/20の実績は「8月度」)。
一方、現場往復(勤務時間外往復)はこの締めとは無関係に、単純な暦月(1日〜末日)で集計され、
翌月へ繰り越しません。日々の入力自体はカレンダー通りの月(1〜31日)で行い、集計時にサーバー側で
自動的に正しい期間へ振り分けられます。

## 注意

- 元のExcel(`日報\出勤表.xlsx`)には計算式がなく、`時間計`や有休の残日数は手書き運用でした。
  本アプリでは `時間計 = 基準時間 − 遅刻 − 早退 − 欠勤 + 早出/残業 + 休出` で自動計算する仕様に
  しています。実際の運用と差異があれば、`db.py` の `calc_total_hours` 相当のロジック(`static/app.js`
  の `recalcTotal` と `db.py` の計算式)を調整してください。
- 有給休暇の残日数(繰越)は自動計算しておらず、その月に取得した有休の合計時間のみを表示します。
